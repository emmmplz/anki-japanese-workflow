# 更新已有 Anki 词包

先备份 Anki 收藏。在补充音频的工作流中保留旧笔记 GUID、模型 ID、原字段顺序、卡片模板方向和牌组身份；为正面静音追加的派生字段应在原字段之后。新词包中的笔记必须与旧包匹配，单纯改成同名牌组并不能保证保留进度。

导出新包后，先在隔离收藏中导入旧包，再导入新包，核对笔记/卡片身份、更新数量和代表卡的复习状态。可选工具 `skills/anki-japanese-v1/scripts/validate_import_update.py --help` 需要独立安装兼容的 Anki Python 库；不同 Anki 版本的导入行为可能不同。完整操作与验证范围见 [交付说明](../skills/anki-japanese-v1/references/delivery.md)。

确认结果后，在 Anki 中导入新包并选择适合现有收藏的更新方式，检查若干已学习卡片的间隔和到期时间。导入界面可能因 Anki 版本而异；若出现大量新卡、重复笔记或字段冲突，停止并从备份恢复后排查，不要继续同步。

生成 `.apkg` 不会自动写入当前收藏或同步账户。
